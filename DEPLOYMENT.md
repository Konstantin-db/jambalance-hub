# Публикация Рабочей Станции

Исходный код сайта хранится в GitHub, а опубликованные файлы обслуживает хостинг REG.RU. Workflow `.github/workflows/deploy-reg-ru.yml` синхронизирует сайт с REG.RU по защищённому FTPS.

## Однократная настройка

1. Откройте настройки репозитория: **Settings → Secrets and variables → Actions**.
2. Нажмите **New repository secret**.
3. Введите имя секрета `REG_RU_FTP_PASSWORD`.
4. Вставьте пароль хостинга для учётной записи `u3551193` и сохраните. Не отправляйте пароль в чат и не добавляйте его в файлы репозитория.
5. Откройте **Actions → Publish Workstation to REG.RU → Run workflow**, выберите ветку `main` и запустите публикацию.

При первом запуске дождитесь зелёного статуса. После этого изменения сайта в `main` будут публиковаться автоматически. Повторную публикацию можно запускать вручную из вкладки **Actions**.

## Что публикуется

В корень сайта `hub.jam-balance.ru` загружаются файлы проекта; SQL-миграции из `supabase/` и файлы настройки GitHub в сайт не копируются. Публикация использует FTPS с проверкой сертификата. Workflow не очищает каталог целиком и сохраняет серверные `.htaccess` и `.well-known/`.

Workflow запускается при изменениях в `main`, кроме изменений только в `.github/`, `DEPLOYMENT.md` или `supabase/`. Для этих случаев доступен ручной запуск.
